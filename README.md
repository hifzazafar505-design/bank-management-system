# 🏦 Bank Management System

A simple **console-based Bank Management System built with Python**.

## 📌 Project Overview

This project allows users to manage bank accounts through a simple menu-driven program.

## ✨ Features

* ➕ Add Account
* 📋 Show Accounts
* 🔍 Search Account
* ✏️ Update Account
* 💵 Deposit Money
* 💸 Withdraw Money
* 🔄 Transfer Money
* 🗑️ Delete Account
* 🚪 Exit

## 🧠 Concepts Used

* Variables
* Input
* Lists
* Dictionaries
* Loops
* Functions
* Conditions

## 🛠️ Technology

* Python 3

## ▶️ How to Run

Make sure Python 3 is installed.

Run the following command:

```bash
python bank_management_system.py
```

## 📋 Example

The program provides a menu where the user can choose different banking operations such as adding an account, depositing money, withdrawing money, or transferring money between accounts.
